# Performing AI

Static workshop website for **Performing AI: A Critical Making Workshop on Perceived AI Aesthetics**.

## Pages
- `index.html` — Home / workshop introduction
- `schedule.html` — Workshop schedule
- `cfp.html` — Call for Participation
- `organizer.html` — Organizer
- `documentation.html` — Documentation / future exhibition archive
- `styles.css` — Shared styling

The site contains no build step and can be served directly through GitHub Pages.
